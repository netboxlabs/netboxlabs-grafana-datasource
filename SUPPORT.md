# Getting support

The NetBox data source for Grafana is an open source project maintained by
[NetBox Labs](https://netboxlabs.com).

## How to file an issue

- **Bug reports and feature requests** go through
  [GitHub issues](https://github.com/netboxlabs/netboxlabs-grafana-datasource/issues/new/choose).
  Pick the matching template — the version and environment fields it asks for are what we
  need to reproduce a problem, so please fill them in.
- **Questions and usage help**: check the [README](./README.md) (configuration, enrichment
  recipes) and [docs/](./docs) first. If the docs don't answer it, open an issue using the
  documentation template — an unanswerable question is a documentation gap.
- **Security vulnerabilities**: do **not** open a public issue. Report privately per
  [SECURITY.md](./SECURITY.md).

Customers with a NetBox Labs support contract can also raise plugin issues through their
usual [NetBox Labs support](https://netboxlabs.com/support/) channel.
